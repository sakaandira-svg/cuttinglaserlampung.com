# Agent rules

- This repository is isolated to CuttingLaserLampung.com. Never read, copy, or modify other workspaces.
- Mission: legitimate local search visibility and WhatsApp conversion for laser cutting, CNC, material processing, and architectural fabrication in Lampung.
- Never invent business data, reviews, project history, prices, capabilities, addresses, coordinates, awards, or testimonials.
- Do not create doorway pages, keyword-stuffed copy, or thin material/location duplicates.
- Preserve Astro static-first architecture and keep client JavaScript minimal.
- Use `src/config/business.ts` for real-world entity inputs and keep missing inputs obvious.
- Run `npm run verify` and `npm run build` after meaningful changes.
- Target accessible, responsive, low-CLS pages with semantic HTML, focus states, and reduced-motion support.
- Deployment target is Hostinger static output from `dist/`, with production domain `https://cuttinglaserlampung.com`.
