# SEO architecture

| Query cluster / intent | Dominant URL | Role |
| --- | --- | --- |
| cutting laser Lampung, jasa laser cutting Lampung | `/` | Commercial hub and brand/entity introduction |
| jasa laser cutting, material dan aplikasi | `/layanan/` | Service index and internal link hub |
| plat besi, stainless, acrylic, ACP, MDF | Matching `/laser-cutting-.../` URLs | Material-specific commercial guidance |
| CNC router Lampung | `/cnc-router-lampung/` | Distinct process intent |
| pagar laser cutting | `/pagar-laser-cutting-lampung/` | Application intent |
| fasad, partisi | Matching application URLs | Architectural application intent |
| portfolio pekerjaan | `/portfolio/` | Trust and conversion support |
| area layanan Lampung | `/area-layanan/` | Legitimate service area context, not doorway pages |
| preparing design files | `/panduan-file-desain-laser-cutting/` | Informational support that assists conversion |
| contact / quotation | `/kontak/` | Conversion destination |

Current status: the architecture remains intentionally narrow and non-duplicative. No additional city pages or near-duplicate pages were introduced. Anchor text and internal links continue to funnel toward conversion while preserving the Lampung service-area focus.

Overlap review: the commercial pages share the same broad intent cluster but remain differentiated by material, process, or application. This is acceptable without keyword stuffing because each page adds unique usage context and preparation guidance.
