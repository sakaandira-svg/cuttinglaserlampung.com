# SEO maintenance

Keep one dominant search intent per URL. Add a page only when it provides substantial unique usefulness and a distinct commercial or informational role.

The site now uses the verified local entity data for Cutting Laser Lampung and avoids unsupported business claims. Titles and descriptions remain aligned with the visible service offer and Lampung service area.

Before publishing new content:

- assign a primary query cluster and canonical URL
- write a unique title and description
- add at least one useful internal link in context
- avoid unsupported capabilities, pricing, reviews, and local claims
- ensure structured data matches visible copy
- test build output, canonical, sitemap, and 404 behavior
- verify WhatsApp, maps, address, and email links against the verified business data

Review business entity data against the official Google Business Profile whenever those inputs change.
