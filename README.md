# CuttingLaserLampung.com

Static Astro website for laser cutting, CNC, material processing, and architectural fabrication services in Lampung.

## Local development

Requires Node.js 22 LTS.

```bash
npm install
npm run dev
npm run build
npm run verify
```

Before launch, complete `docs/OPERATOR-INPUTS.md`. Deployment guidance is in `docs/HOSTINGER-DEPLOYMENT.md`.
